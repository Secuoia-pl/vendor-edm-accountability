## One-line frame (PL)
Problem nie zaczyna się w momencie ataku — zaczyna się, gdy milion ludzi jest zależnych od jednego vendora bez równoważnej odpowiedzialności.

## What this page is
Public research note on accountability when a healthcare software vendor (EDM / clinic software) is breached: facts checklist, five reusable questions, 72h controller checklist, FAQ. Case lens: MyDr (Poland, Aug 2026). Not legal advice.

## Key shift
From: "Was there a hack?" / "Just reserve PESEL"
To: "What ex-ante duties should a nationwide-scale vendor have — and how does a patient learn if they are in scope?"

## Five questions
1. Minimum security baseline for vendors serving thousands of clinics?
2. Incident notification SLA to controllers (content + deadline)?
3. Practical path for a citizen to learn "am I in scope" within days?
4. Which contract rights (audit, sub-processors, exit) were enforceable before the incident?
5. What ex-ante standard changes before the next vendor incident?
